**Design decisions** (the contract's four + the forced ones):
- **`setPrinting` addresses the CARD** — every entry of that card, not one (zone, card) pair. Forced by the data model: `EditorCard.image` is per card (and `hydrate` keys the map by cardId), so per-zone choices could never render distinctly; commander+main double residency gets one look and both rows carry the same printingId on the wire.
- **Rows cache per card id in the pane instance's state** (`printingsByCard` map + a `startedRef` in-flight guard; failed fetches clear the guard so "Try again" is real). The tools pane and the phone sheet are separate instances with separate caches — only one is interactable per tier, so "one request per card per pane session" holds where it matters.
- **Open state and selection are per card by derivation** (`openFor === card.id`, `selected.cardId === card.id`): switching cards closes the collapsible and clears the selection, returning re-opens against the cache with no refetch.
- **Row markup**: compact `<ul>` list per the D5 sketch — 26×36 thumb (`thumbnailUrl`: Scryfall `small`, blank spacer for OP), setName + "· In deck" marker, `CODE NUM`, USD (games with prices only). `printingCaption` is reused on the "In deck:" line ("In deck: default printing · FDN · #204 · Rare" / "In deck: SLD · #2407 · Rare"; an explicit printing beyond the fetched 250 reads "another printing").
- **The trigger shows the count only once fetched** ("Printings" → "Printings · 15") — the editor can't know N without the request R2 forbids making eagerly. **N=1 stays honest** (one row renders; forced by fetch-on-open, and it genuinely answers "does this card have alt printings").
- **Choosing a row always pins it explicitly** — applying the default row writes its printingId rather than clearing to null (only reachable when the entry currently differs; the button is disabled when selection == what the deck uses). "Use THIS printing" means this exact printing; a future default re-point won't silently swap it. Clearing back to follow-the-default has no D5 control and none was invented.
- **Not-in-deck cards get the list but no controls** (no "In deck:" line, no button) — the TagEditor idiom: deck controls render only when the card has an entry. Previewing rows works for any card.
- **Est. price footnote** inside the collapsible ("Price estimates keep using each card's cheapest printing.") for priced games only — the D5 bullet's "the pane says so".
