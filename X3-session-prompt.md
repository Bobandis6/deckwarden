## Design decisions to make explicitly (disclose + pin each)

- **The route**: `GET /api/combos/[key]` → `{ combo, cards }` — pieces in which order (the commander first, then name?), wires with Commander legality (`FORMAT_ID.commander`), the key validated by `^[0-9]+(-{1,2}[0-9]+)*$` and a length cap; an unknown key → 404 with the cache header (a deliberate difference from `cards/[id]/combos`); a removed piece → say what happens.
