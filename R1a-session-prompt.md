## Design decisions to make explicitly (disclose + test-pin each)

- **Token encoding:** write the REDESIGN.md §1 values as hex in `globals.css` (CSS accepts it; shadcn's oklch was a default, not a rule) so `src/lib/theme/tokens.ts` can hold the same strings and the vitest can assert exact equality by parsing `globals.css` from disk (`:root` block ↔ `tokens.light`, `.dark` block ↔ `tokens.dark`, accents, OG). Add `--brand`, `--accent-mtg`, `--accent-optcg`, `--accent-game` to `@theme inline` as `--color-*` so utilities exist; `[data-game="mtg"] { --accent-game: var(--accent-mtg) }`, same for `optcg`, plus the `--ring` override. `--mana-*` untouched.
- **Motion policy:** one `@media (prefers-reduced-motion: reduce)` block in `@layer base` that collapses animation and transition durations to 0.01ms for everything (the standard form) — decorative motion is additionally written `motion-safe:` from R1a on; document the convention in a comment at the block.
- **Appearance menu (interim placement):** a small client `AppearanceMenu` (Base UI Menu: Dark / Light / System, current choice checked) rendered in `SiteFooter` this session and moved into the header in R1b; theme changes must not touch deck state (they cannot — the provider is outside the editor — assert it anyway in the prod pass: switch theme mid-edit, save status unchanged, no POST `/api/decks`).
- **`Modal` becomes a wrapper over the installed Dialog:** same `label / onClose / wide / children` signature so the six call sites do not change; `wide` maps to a size class; Base UI supplies the focus trap, Escape, outside-press dismiss, and focus restore. `DeleteAccount` moves to AlertDialog. **First component test of the repo:** `src/components/ui/modal.test.tsx` — renders the wrapper, asserts `role="dialog"` with the accessible name, Escape calls `onClose`, focus lands inside on open; this sets the RTL house pattern (add `setupFiles` with cleanup if needed and say so).
- **Icon swap policy:** chrome glyphs → lucide with `aria-hidden` next to visible text, or an `aria-label` when the glyph was the only label (the ✕ close buttons); content glyphs (♥ ♡, the ✓ in "✓ Legal … deck" and owned marks, × as a quantity sign) stay text this session — R3 owns the validation line. Size via Button's existing `[&_svg]` rules; standalone icons `size-4`.
- **OG unification:** `og/elements.tsx` reads `BG/FG/MUTED` from `tokens.ts`; `OgKicker` and the curve bars take an `accent` chosen by game id (`deckOgLabels` already knows the game) — MTG `#B5A2FF`, OP `#62D6C5`, generic `#A5B4FC`; the attribution chip and the artless-OP posture unchanged. Pin: `src/lib/og/labels.test.ts` (or a sibling) asserts the accent-per-game lookup.
- **Both-theme contrast is the acceptance bar** (§1 ratios): status colors (`text-destructive`, the amber/emerald status tones, the legality chips on `/cards/[id]`) must read in both themes without `dark:` hacks where a token exists; where a hue has no token, keep the `dark:` pair and say which.
