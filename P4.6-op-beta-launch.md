## img.deckwarden.gg runbook (owner console work, ~20 min active)

Verified against developers.cloudflare.com, vercel.com/kb, and kb.porkbun.com
on 2026-09-07. Two parts; part 2 requires part 1 **Active**.

**Part 1 — move deckwarden.gg's DNS zone to Cloudflare (registrar stays
Porkbun):**

1. Cloudflare dashboard → **Domains** → **Onboard a domain** →
   `deckwarden.gg` → choose the **Free** plan (DNS is $0, queries
   unmetered).
2. **Review the imported records against Porkbun's DNS editor line by
   line.** Cloudflare's quick scan is explicitly not guaranteed complete —
   custom-named TXTs (DKIM `default._domainkey`, `_dmarc`) are the
   documented weak spot. Must survive the move:
   - Apex `A` → Vercel (76.76.21.21, or whatever the Vercel dashboard
     shows for the project) and `www` CNAME → `cname.vercel-dns-0.com`
     (ditto).
   - `MX` @ → `fwd1.porkbun.com` (prio 10) and `fwd2.porkbun.com` (prio
     20), `TXT` @ → `v=spf1 include:_spf.porkbun.com ~all`, plus any
     DKIM/DMARC TXTs present. **contact@deckwarden.gg forwarding is
     load-bearing** — the site's Contact links use it (P2.8 verified the
     forward; re-test after the move, from another account — Gmail hides
     self-sent tests).
3. **Set the Vercel A and CNAME records to "DNS only" (grey cloud).**
   Vercel's current guidance is flatly anti-proxy ("we do not recommend
   using a reverse proxy in front of Vercel") — orange-clouding them
   causes error 525 / failed cert renewals. Grey-cloud DNS hosting is
   exactly what their KB prescribes. MX/TXT have no proxy toggle.
4. Continue → copy the two assigned nameservers exactly.
5. If DNSSEC is enabled at Porkbun, **disable it before** changing
   nameservers (an active-DNSSEC nameserver change can take the domain
   offline).
6. Porkbun → **ACCOUNT → Domain Management** → deckwarden.gg **Details** →
   **Nameservers** edit → remove all four Porkbun entries, add the two
   Cloudflare ones → save/submit.
7. Wait for the zone to flip to **Active** (Cloudflare emails; up to
   24–48h, usually a few hours). Verify: `dig NS deckwarden.gg +short`,
   then that the site loads and the email forward still works.

**Part 2 — attach the custom domain to the bucket:**

8. Cloudflare → **R2 object storage** → bucket **`deckwarden-public`** →
   **Settings** → **Custom Domains** → **Add** → `img.deckwarden.gg` →
   Continue → review the record it will create → **Connect Domain**.
   (Only this bucket. **`deckwarden-backups` never gets a public
   domain** — it holds pg/ dumps.)
9. Status goes **Initializing → Active** in minutes (refresh; "Retry
   connection" if stuck). The r2.dev URL keeps working alongside — no
   downtime window, leave it enabled.
10. Test before flipping anything:
    `https://img.deckwarden.gg/optcg/images/OP15-058.png` should serve
    Enel. Caching is automatic on the custom domain (png is on
    Cloudflare's default cached-extension list); optionally enable Smart
    Tiered Cache (recommended for R2).
11. **The flip** (this half can be handed back to a session): set
    `R2_PUBLIC_IMAGE_BASE=https://img.deckwarden.gg/optcg/images` — same
    path shape as the current r2.dev value, check `.env.local` for the
    exact suffix — in `.env.local` AND `gh secret set
    R2_PUBLIC_IMAGE_BASE`, then one `gh workflow run nightly-ingest.yml`:
    punk-records' skip-check tuple includes `image_base`, so the dispatch
    re-points all ~4.8k `image_override`s, exactly like the P4.1 r2.dev
    flip. Verify site-wide OP images serve from the new domain, then mark
    LATER row 51 fired.
12. Optional, free, rides the zone: Cloudflare **Web Analytics** (the
    Launch Playbook §10 nicety — a checklist line, nothing more).

## Recorded decisions (the P4.6 design calls)

1. **Two-game identity, smallest honest diff.** Default title + og:title →
   "Deckwarden — Commander & One Piece deck builder" ("Commander deck
   builder" stays a literal substring — the indexed phrase); DESCRIPTION
   names both games; hero h1 went game-neutral with both games in the
   subtitle. Per-page titles ride the `%s · Deckwarden` template
   untouched — seo-smoke pins both directions (widened home, unmoved /c/
   titles).
2. **OP deck OG posture: artless, game-true words.** `deckOgLabels()`
   (test-pinned): kicker "One Piece deck", "Cost curve", no art fetch —
   the P4.1/P4.4 call (no Bandai art in generated images while permission
   is unanswered) extends to deck unfurls; leader art from our own R2
   would be a posture *extension*, deliberately not taken. Bonus: OP
   unfurls no longer make a doomed Scryfall API call each.
3. **CTA hub: Enel (op15-058)** — data over vibes (230 finishes/86 events,
   top current-meta win rate); Luffy op13-001 is the recognizability
   alternate with 110.
4. **The funnel fixes shipped** (each test- or smoke-pinned): Limitless
   export lines resolve via their trailing `(CODE)` (resolve Pass 0);
   pasted leader lines route to the leader zone (`importZoneFor` adapter
   hook); re-importing the card already filling a capped zone is a silent
   no-op (idempotent import — kills the "moved Gamma Knife to Deck"
   self-contradiction, whose fallback text is also fixed); hub CTA
   latches the leader via `?leader=` (draft contract intact — no row
   until a real edit); OP search results/suggestions/preview show the
   printed id (two Enel *leaders* exist); placeholders speak OP; sample
   hand draws 5 (the full-redraw mulligan already matched OP rules);
   share pages carry the Bandai posture line; /legal credits Topdeck +
   Limitless.
5. **DNS/img flip deferred by owner choice (2026-09-07)** — runbook above
   is the top checklist item; LATER row 51 sharpened to say "announce
   after the flip, or knowingly accept r2.dev throttling."
