## Design decisions to make explicitly (disclose + test-pin each)

1. **Where the commander guess lives.** Recommended: an OPTIONAL adapter hook, e.g. `importLeaderGuess?(lines: readonly ParsedLine[], cards: readonly (CardWire | null)[]): number[]`, returning the indexes of lines to route to the leader zone. MTG implements it as a pure function (a new `src/lib/games/mtg/import-guess.ts` or beside the tokenizer) that reuses commander eligibility (export `isEligibleCommander` from validate.ts or move it to a shared MTG helper; don't duplicate the exception set). `buildImportItems` calls it only when NO line carries a leader-zone hint, and applies it to those items only. The core stays game-ignorant; One Piece doesn't implement it (its leaders already route by category). Reject (B), always promoting line 1 when eligible: MTGO and hand-typed lists that happen to start with a legendary creature in the 99 would be mis-promoted, which is exactly what the types.ts docblock forbids. Reject (C), a core-level rule in `import.ts`: game knowledge in core breaks the adapter contract. Reject (D), guessing in the tokenizer: it has no resolutions, so no eligibility.
2. **The rule (Moxfield's shape), exactly.** Let `n` = lines and `cmp = new Intl.Collator("en").compare` over rawNames. Guess `k` (1 or 2, the zone's max) when ALL hold: (i) no line has a `commander` zoneHint (any header or marker disables the guess); (ii) lines `0..k-1` each resolved AND commander-eligible; (iii) `cmp(line[k-1], line[k]) > 0` (the break); (iv) lines `k..n-1` are non-decreasing under `cmp`; (v) try `k = 1` first, then `k = 2`. Pins: the owner's paste → exactly Toph; "Aang, Airbending Master" (eligible, line 2) is NOT promoted, because Aang < Abandoned breaks nothing. A partner pair (two eligible lines, then a sorted remainder) → both. A list whose commander sorts first alphabetically (e.g. commander "Aang, …" then "Abandoned Air Temple …") → NO guess, disclosed as the known miss. An unsorted hand list → no guess. A paste with any `Commander` header or `*CMDR*` → no guess (the hint path). The existing "Moxfield text export" fixture shape (Atraxa, then Arcane Signet …, 10 Forest, then `SIDEBOARD:`) → Atraxa guessed. Decide whether section headers like `SIDEBOARD:` end the sorted run (recommended: evaluate (iv) only over lines with no zoneHint) and pin it. The Sokka canary (the full owner paste under a code-unit comparator would fail (iv)) is pinned by using the real fixture.
3. **Make the guess visible and safe in add mode.** Recommended: `ImportItem` gains `guessed?: true`. The review step shows one line above the buttons, e.g. "Commander: Toph, the First Metalbender — from the first line of the list", so a wrong guess is caught before apply. In `applyImport`, a GUESSED leader line in `"add"` mode, when the leader zone already holds a DIFFERENT card, routes to the default zone with no warning (a hinted line keeps today's behavior). The same card already there stays the idempotent silent skip. Replace mode applies the guess. Pin all three.

Pin with the owner's paste plus a typed `Commander` header line: 79 spilled → 1 warning. Leave the header latch in the tokenizer alone (Arena and MTGGoldfish rely on it). The done dialog's count follows automatically.
