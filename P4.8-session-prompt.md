## Design decisions to make explicitly (disclose + test-pin each)

1. **Where the id pass lives.** (A) — recommended — in the search route: after zod, `const idKey = params.name ? classifyResolveToken(game, params.name) : null` (or the prefix helper of decision 2); when it names a key, run the SAME select / join / `NOT is_removed` / legality path over an `external_key` condition and return the same response shape (`total` via `count(*) over()`, the same `Cache-Control`), never touching the translator; otherwise the existing path, byte for byte. The route already asks the registry for the adapter; the classifier is core and game-branched by the `game` param — P4.1's precedent, not a new coupling. Reject (B) a declarative field — `external_key` added to `FieldTarget` (types.ts 167–179) and `COLUMNS` (translate.ts 27–36), `{ key: "id", kind: "text", target: { column: "external_key" }, match: "exact" }` on the One Piece adapter, the pane AND `/cards` classifying client-side and sending `id=` instead of `name=` — more moving parts (types, translator, adapter, two clients, four test files) for the same single query, and prefix behavior would need a fourth `match` kind; say why in the route's docblock (1–12). Reject (C) the pane calling `/api/cards/resolve` for id-shaped input — 20 / min per IP against 200 ms-debounced typing, `no-store` against the search route's 300 s CDN cache, and a second fetch path in a pane R3 deliberately made thin.
2. **Exact vs prefix.** Exact-only (the row's literal ask) leaves every keystroke before the last digit reading "No cards match “OP01-02”." — the reducer drops that verdict on the next input (search-state.ts 82–92), so the finished id shows its row, but the flash is real. PREFIX from the hyphen — an id-shaped prefix `^[A-Z]+\d*-\d*$` after uppercasing: "OP01-" → the OP01 set capped at `limit`, "OP01-02" → the ten above, "OP01-025" → one — makes the box a card-number browser with the arrow keys, at 1.078 ms on the existing index. **Recommend PREFIX**, One Piece only (a game branch like the classifier's — Magic returns null), `ORDER BY external_key ASC, name_norm` (the `sort` param ignored on this path — say so in the docblock), `limit` / `offset` honored, `total` honest.
